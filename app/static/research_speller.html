입력 실험실 사용 설명서

한 문장 단위의 입력 루프

  1. 비교 조건과 목표 문장을 설정하고 ‘새 문장 시작’을 누릅니다.
  2. 단어 또는 문장 섹션을 고릅니다. 40키 또는 컴퓨터 키보드로 입력합니다. 자음 뒤 모음은 한글 음절로 조합됩니다. 정확한 받침·복합 자모는 PC 한글 입력기로도 입력할 수 있습니다.
  3. ‘후보 조회’로 초성과 문맥에 맞는 표현을 찾고 원하는 후보를 선택합니다. 이 클릭을 향후 SSVEP 판별 결과로 대체할 수 있는 단계로 분리했습니다. 실제 주파수 자극은 없습니다.
  4. 후보가 없으면 입력을 고쳐 다시 조회하거나 ‘입력한 그대로 추가’를 누릅니다. 입력·선택·조회는 문장 종료까지 반복합니다.
  5. ‘문장 종료’로 평가를 저장합니다. 다시 시작하기 전에는 완료한 문장이 유지됩니다.

빠른 후보와 개인화

단어는 선택한 단어만, 문장은 종료한 전체 문장만 별도 빈도로 기억합니다. 단어 정의는 띄어쓰기 없는 어절입니다. 자동완성은 초성/글자 접두어 일치, 연관 표현은 공통 단어 기반 개인 사전 검색으로, 의미 이해 모델은 아닙니다. 예시 사전과 개인 표현은 출처를 표시합니다.

빠른 LLM 조건은 생성 후보 수를 줄이고 별도 LLM 정렬과 추가 다양성 생성을 생략합니다. 같은 입력·문맥·단위·조건은 이 탭에서 60초 동안 재사용합니다. 개인 후보가 있으면 먼저 보여주고 서버 결과가 오면 별도로 덧붙입니다. 입력이 바뀌거나 조회를 취소하면 늦은 결과를 폐기합니다.

실험과 한계

직접 입력 / 개인 표현 / 빠른 LLM / 기존 LLM을 동일 목표로 비교하세요. 문장 시간은 실제 경과시간(대기 포함), 입력 동작은 화면 키·PC 입력 이벤트·후보 선택·수정, 문자 오류율은 목표와 완성 문장의 편집거리/목표 문자 수입니다. 목표·조건은 시행 중 고정됩니다. 새로고침은 진행 중 시행을 중단합니다. 원문은 평가 JSON에 포함하지 않습니다.

LLM을 쓰는 이유는 사용자가 모든 글자를 입력할 부담을 줄이기 위해서입니다. 생성 대기와 오추천 수정까지 포함한 총시간이 더 길다면 이 조건에서는 이득이 없는 것입니다. 실제 ALS 사용자 성능·피로·EEG 성능은 별도 평가가 필요합니다.

연구 근거

  • SpeakFaster (2024): 약어 입력과 사용자 수정 흐름. 본 화면은 한국어에 맞춘 응용이며 논문의 성능 수치를 재현한 것이 아닙니다.
  • ChatBCI (2026): 문맥 기반 단어 예측을 통한 입력 지원.
  • MindChat (2025, 사전논문): 실제 상황 문맥을 고려한 BCI spelling. 본 실험실에서는 EEG 해독을 수행하지 않습니다.

개인정보

후보 조회에는 입력 초성과 완성한 일부 글자, 작성 중 문장, 직접 작성한 상황이 서버·언어 모델로 전송됩니다. 목표 문장은 보내지 않습니다. 단어·문장 기억은 현재 탭의 세션 저장소에 저장됩니다. 공용 기기에서는 ‘개인 표현 기억 삭제’를 사용하세요. 평가 결과는 다운로드 전까지 메모리에만 있습니다.
