이심전심 사용 설명서

내가 원하는 말을, 나의 속도로.

초성으로 문장을 찾고, 뜻에 맞게 고친 다음 상대방에게 보여주거나 소리로 전하세요. 설명서를 닫으면 작성 중이던 화면으로 돌아갑니다.

처음 사용하기글자 수정확정·말하기설정·기록문제 해결

1. 세 단계로 시작해요

  1. 대화 상대와 상황 선택: 가족, 친구 등 상대와 현재 상황을 선택합니다. 후보를 찾는 데 참고됩니다.
  2. 초성 입력: 예를 들어 ‘물 줘’는 ㅁ → ㅈ을 누르고 ‘후보 생성’을 선택합니다. 띄어쓰기와 문장 부호는 입력하지 않습니다. 한 번에 최대 20글자까지 입력할 수 있습니다.
  3. 추천 표현 확인: 원하는 문장이면 ‘문장 확정’을 누릅니다. 확정한 문장은 위쪽 ‘내가 전할 말’에 추가됩니다.

추천 문장은 예측 결과입니다. 화면에 표시된 내용을 읽고, 내 뜻과 맞는지 확인한 뒤 확정하세요.

2. 원하는 표현으로 고치기

한 글자만 바꾸고 싶다면 · FillMask

추천 문장에서 바꿀 한글 글자 버튼을 누르세요. 해당 위치만 바꾼 대안을 조회합니다. 원래 입력한 초성과 맞는 대안이 없으면 결과가 없을 수 있습니다. 대안의 문장을 확인한 후 ‘문장 확정’을 눌러야 추가됩니다. 글자를 누르는 것만으로는 문장이 추가되지 않습니다.

일부 글자를 확실히 알고 있다면 · KeywordAE

추천 영역의 ‘원하는 표현이 없어요 → 직접 입력하기’를 열고, 수정할 초성 칸을 고릅니다. 모음과 받침을 선택해 글자를 완성한 뒤 ‘이 글자로 다시 찾기’를 누르세요. 일부 글자만 완성하면 나머지를 다시 예측합니다. 모든 글자를 완성한 경우에는 완성된 문자열이 바로 추가됩니다.

문장 전체를 직접 쓰고 싶다면

입력 영역의 ‘원하는 말이 없나요? 문장을 직접 입력하기’를 열고 원하는 문장을 쓴 뒤 ‘입력한 문장 확정’을 누르세요. 언어 모델 조회 없이 입력한 그대로 추가하므로 서버 연결이 끊겨도 사용할 수 있습니다.

3. 확정하고 말하기

  • 문장 말하기: 확정된 문장을 기기의 음성으로 읽습니다. 소리가 재생되지 않으면 기기 음량과 한국어 음성 지원을 확인하세요.
  • 말하기 중지: 재생 중인 음성을 멈춥니다.
  • 마지막 문장 취소: 최근에 추가한 문장을 되돌립니다. 새로고침 뒤에는 이전 실행의 취소 기록이 남지 않습니다.
  • 지우기 / 초성 초기화: 마지막 초성 하나 / 입력한 초성 전체를 지웁니다.
  • 전체 초기화: 현재 작성 중인 말과 초성을 비웁니다. 개인 기록 삭제는 별도 설정에서 합니다.

1~5는 현재 표시된 후보 확정, Esc는 진행 중인 조회 취소입니다. 입력 칸을 편집할 때는 후보 단축키가 동작하지 않습니다. 설명서에서는 Esc로 닫을 수 있습니다.

4. 나에게 맞게 조절하기

  • 큰 글씨: 화면 위쪽 ‘가 큰 글씨’로 입력·후보·주요 버튼을 확대합니다. 같은 버튼으로 기본 크기로 돌아옵니다.
  • 자동 후보 조회: ‘입력 설정 · 이 탭의 기록’에서 켭니다. 초성 2개 이상 입력 후 1.2초 동안 입력을 멈추면 조회합니다. 문장은 자동 확정되지 않습니다.
  • 후보 수: 3개 또는 5개로 선택합니다.
  • 대화 문맥: ‘자주 쓰는 표현 · 대화 문맥’을 열어 상대방의 말이나 상황을 적으면 조회에 참고합니다. 최근 대화도 자동 반영됩니다.
  • 자주 쓰는 표현: 확정한 표현이 모입니다. 이 버튼은 누르면 바로 문장에 추가됩니다.

내 대화는 어디에 저장되나요?

작성 중인 문장과 최근 대화, 자주 쓰는 표현은 현재 브라우저 탭의 세션 저장소에 보관되어 새로고침 뒤 복원됩니다. 후보 조회 시 초성·문맥 등 필요한 입력이 서버와 언어 모델로 전송됩니다. 탭 복원 기능에 따라 기록이 다시 열릴 수 있으므로 공용 기기에서는 ‘이 탭의 기록 삭제’를 사용하세요.

‘사용 지표 내려받기’는 입력 횟수·조회 지연시간 등의 JSON 파일을 저장합니다. 문장 원문은 포함하지 않습니다. 실제 EEG 정확도나 의사소통 성능을 측정하는 기능은 아닙니다.

5. 잘 안 될 때

후보가 늦게 나오거나 연결 오류가 보여요

서버가 절전 상태에서 깨어나는 데 시간이 걸릴 수 있습니다. 잠시 후 ‘후보 생성’을 다시 눌러보세요. 입력은 유지됩니다. ‘조회 취소’로 중단하거나, 기다리지 않고 문장 전체를 직접 입력할 수도 있습니다.

원하는 표현이 없거나 초성을 잘못 눌렀어요

‘지우기’로 잘못 입력한 초성을 수정하세요. 글자 하나의 대안은 FillMask, 일부 글자를 지정하는 것은 KeywordAE, 정확한 문장을 알고 있을 때는 전체 직접 입력을 사용하세요.

눈으로 바라보면 선택되나요?

현재 웹 버전은 클릭·터치·키보드로 조작하는 연구용 인터페이스입니다. EEG 측정, 시선 추적, P300/SSVEP 자극 및 실제 뇌파 선택 기능은 활성화되어 있지 않습니다.

새 대화와 기록 삭제는 어떻게 다른가요?

‘새 대화 시작’은 상대와 상황을 다시 선택하며 현재 대화를 초기화합니다. 자주 쓰는 표현은 유지됩니다. 개인 기록까지 비우려면 ‘입력 설정 · 이 탭의 기록’의 ‘이 탭의 기록 삭제’를 선택하세요.
