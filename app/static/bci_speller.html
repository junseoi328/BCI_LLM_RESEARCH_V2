Pseudo-online 실험 모드 · 결과 내보내기

실험 모드를 켜면 키를 누른 뒤 자극(점멸) 창이 유지되고 설정한 정확도로 오판독이 주입됩니다(MindChat SSVEP 90% 기준). 동적 정지를 켜면 요즘 SSVEP 스펠러처럼 판독 확신도가 문턱을 넘는 순간 자극을 끊습니다 — 쉬운 시행은 짧게, 어려운 시행만 길게 봅니다(Stawicki 외, PLOS ONE 2019). 짧게 끊은 만큼 판독 정확도는 낮아지도록 모형화했습니다. 모든 시행의 구간별 시간·자극 길이·오판독 여부가 CSV에 기록됩니다.

원하는 말이 없나요? 문장을 직접 입력하기
입력 설정 · 자주 쓰는 표현 · 이 탭의 기록

화면 배열 = 컴퓨터 자판 배열입니다. 두벌식 자판을 그대로 옮겨 놨으니 손이 아는 자리를 눈이 그대로 따라가면 됩니다 — 2행 ㅂㅈㄷㄱㅅ ㅛㅕㅑㅐㅔ, 3행 ㅁㄴㅇㄹㅎ ㅗㅓㅏㅣ, 4행 ㅋㅌㅊㅍ ㅠㅜㅡ , . ?. ⇧를 누르면 자판과 똑같이 쌍자음(ㅃㅉㄸㄲㅆ)·겹모음(ㅒㅖ)·단어삭제·느낌표로 바뀌고, 한 글자를 누르면 저절로 풀립니다.

물리 키보드도 같은 자리입니다 — q·w·e는 ㅂ·ㅈ·ㄷ, o·p는 ㅐ·ㅔ, 쉼표·마침표·물음표는 , . / 자리 그대로(물음표는 Shift+/). 후보는 숫자 1~7, 띄어쓰기 Space, 문장 확정 Enter, 글자 삭제 Backspace, 단어 삭제 Shift+Backspace 또는 Delete. 한/영 상태와 무관하게 동작합니다.

단어·문장 후보는 항상 즉시(0ms) 채워집니다. 세 층을 차례로 씁니다 — ① 내가 전에 쓴 말(이 기기에 저장), ② 검수된 AAC 표현 사전 281개, ③ 일반 한국어 대화 말뭉치에서 만든 넓은 단어·다음단어 사전. 언어 모델은 로컬이 못 맞힌 나머지만 채웁니다.

지금 무슨 얘기 중인지도 함께 봅니다 — 고른 상황, 여기 적은 상황 메모, 상대가 최근에 한 말(최근일수록 무겁게), 내가 방금 고른 말, 그리고 만들고 있는 문장. 상대가 쓴 단어는 그 단어 자체로도 후보에 밀어 올립니다. 앞 단어는 두 개까지 봅니다 — 사랑해 + 많이 다음에 무엇을 골랐는지를 기억하고, 그런 기록이 없으면 앞 한 단어, 그것도 없으면 자주 쓰는 말 순으로 물러납니다.

넓은 사전 출처: KLUE 벤치마크의 WoS 과제지향 대화(CC BY-SA 4.0)에서 만든 빈도표입니다. 원문은 포함하지 않습니다.

빠른 방식은 추가 모델 호출을 줄입니다. 추천 품질은 달라질 수 있어요. 같은 입력·문맥의 정상 후보는 60초 동안 재사용합니다.

문장과 대화, 자주 쓰는 표현은 이 브라우저 탭에 저장됩니다. 후보 조회 시 입력과 최근 대화가 서버·언어 모델로 전달됩니다.

이심전심 사용 설명서

내가 원하는 말을, 나의 속도로.

초성으로 문장을 찾고, 뜻에 맞게 고친 다음 상대방에게 보여주거나 소리로 전하세요. 설명서를 닫으면 작성 중이던 화면으로 돌아갑니다.

처음 사용하기글자 수정확정·말하기설정·기록문제 해결정보·출처

1. 세 단계로 시작해요

  1. 대화 상대와 상황 선택: 가족, 친구 등 상대와 현재 상황을 선택합니다. 후보를 찾는 데 참고됩니다.
  2. 초성 입력: ‘물 줘’는 ㅁ → ㅈ처럼 초성만 눌러도 되고, ㅁ 다음에 모음 ㅜ를 눌러 ‘무’를 그 자리에서 확정해도 됩니다(받침은 후보가 채워줍니다). 한 번에 최대 20글자입니다.
  3. 후보키로 선택: 키를 누를 때마다 단어 후보가 즉시(로컬·0ms) 갱신되고, 문장 후보는 언어 모델이 0.7초 뒤 채웁니다. 원하는 후보의 번호가 붙은 후보키 1~7(또는 숫자키)을 누르면 바로 확정됩니다. 단어/문장 개수 비율은 로컬에 맞는 단어가 몇 개인지에 따라 자동으로 조절됩니다.

추천 문장은 예측 결과입니다. 화면에 표시된 내용을 읽고, 내 뜻과 맞는지 확인한 뒤 확정하세요.

2. 원하는 표현으로 고치기

한 글자만 바꾸고 싶다면 · FillMask

추천 문장에서 바꿀 한글 글자 버튼을 누르세요. 해당 위치만 바꾼 대안을 조회합니다. 원래 입력한 초성과 맞는 대안이 없으면 결과가 없을 수 있습니다. 대안의 문장을 확인한 후 ‘문장 확정’을 눌러야 추가됩니다. 글자를 누르는 것만으로는 문장이 추가되지 않습니다.

일부 글자를 확실히 알고 있다면 · KeywordAE

추천 영역의 ‘원하는 표현이 없어요 → 직접 입력하기’를 열고, 수정할 초성 칸을 고릅니다. 모음과 받침을 선택해 글자를 완성한 뒤 ‘이 글자로 다시 찾기’를 누르세요. 일부 글자만 완성하면 나머지를 다시 예측합니다. 모든 글자를 완성한 경우에는 완성된 문자열이 바로 추가됩니다.

문장 전체를 직접 쓰고 싶다면

입력 영역의 ‘원하는 말이 없나요? 문장을 직접 입력하기’를 열고 원하는 문장을 쓴 뒤 ‘입력한 문장 확정’을 누르세요. 언어 모델 조회 없이 입력한 그대로 추가하므로 서버 연결이 끊겨도 사용할 수 있습니다.

3. 확정하고 말하기

  • 문장 말하기: 확정된 문장을 기기의 음성으로 읽습니다. 소리가 재생되지 않으면 기기 음량과 한국어 음성 지원을 확인하세요.
  • 말하기 중지: 재생 중인 음성을 멈춥니다.
  • 마지막 문장 취소: 최근에 추가한 문장을 되돌립니다. 새로고침 뒤에는 이전 실행의 취소 기록이 남지 않습니다.
  • 글자삭제 / 단어삭제: 마지막 글자 하나 / 작성 중인 단어(없으면 확정된 마지막 어절)를 지웁니다.
  • 전체 초기화: 현재 작성 중인 말과 초성을 비웁니다. 개인 기록 삭제는 별도 설정에서 합니다.

1~7은 현재 표시된 후보 확정, Esc는 진행 중인 조회 취소입니다. 입력 칸을 편집할 때는 후보 단축키가 동작하지 않습니다. 설명서에서는 Esc로 닫을 수 있습니다.

4. 나에게 맞게 조절하기

  • 큰 글씨: 화면 위쪽 ‘가 큰 글씨’로 입력·후보·주요 버튼을 확대합니다. 같은 버튼으로 기본 크기로 돌아옵니다.
  • 자동 후보 조회: ‘입력 설정 · 이 탭의 기록’에서 켭니다. 초성 2개 이상 입력 후 1.2초 동안 입력을 멈추면 조회합니다. 문장은 자동 확정되지 않습니다.
  • 후보 수: 3개 또는 5개로 선택합니다.
  • 대화 문맥: ‘자주 쓰는 표현 · 대화 문맥’을 열어 상대방의 말이나 상황을 적으면 조회에 참고합니다. 최근 대화도 자동 반영됩니다.
  • 자주 쓰는 표현: 확정한 표현이 모입니다. 이 버튼은 누르면 바로 문장에 추가됩니다.

내 대화는 어디에 저장되나요?

작성 중인 문장과 최근 대화, 자주 쓰는 표현은 현재 브라우저 탭의 세션 저장소에 보관되어 새로고침 뒤 복원됩니다. 후보 조회 시 초성·문맥 등 필요한 입력이 서버와 언어 모델로 전송됩니다. 탭 복원 기능에 따라 기록이 다시 열릴 수 있으므로 공용 기기에서는 ‘이 탭의 기록 삭제’를 사용하세요.

‘사용 지표 내려받기’는 입력 횟수·조회 지연시간 등의 JSON 파일을 저장합니다. 문장 원문은 포함하지 않습니다. 실제 EEG 정확도나 의사소통 성능을 측정하는 기능은 아닙니다.

5. 잘 안 될 때

문장 후보가 늦게 나와요

단어 후보는 언어 모델을 거치지 않으므로 항상 즉시 뜹니다 — 서버가 느리거나 끊겨도 단어 후보만으로 계속 입력할 수 있습니다. 문장 후보만 언어 모델을 기다리며, 이 대기 시간은 위쪽 HUD의 ‘LLM 실대기’에 실측으로 표시됩니다.

원하는 표현이 없거나 초성을 잘못 눌렀어요

‘지우기’로 잘못 입력한 초성을 수정하세요. 글자 하나의 대안은 FillMask, 일부 글자를 지정하는 것은 KeywordAE, 정확한 문장을 알고 있을 때는 전체 직접 입력을 사용하세요.

눈으로 바라보면 선택되나요?

아직 아닙니다. 현재 웹 버전은 클릭·터치·키보드로 조작하는 연구용 인터페이스입니다. 다만 Pseudo-online 실험 모드를 켜면 SSVEP 자극 시간(기본 1.5초)과 판독 정확도(기본 90%)를 흉내 내어, 실제 EEG를 붙이기 전에 전체 루프가 얼마나 걸리는지 측정하고 CSV로 저장할 수 있습니다.

새 대화와 기록 삭제는 어떻게 다른가요?

‘새 대화 시작’은 상대와 상황을 다시 선택하며 현재 대화를 초기화합니다. 자주 쓰는 표현은 유지됩니다. 개인 기록까지 비우려면 ‘입력 설정 · 이 탭의 기록’의 ‘이 탭의 기록 삭제’를 선택하세요.

6. 정보·출처

연구용 프로토타입입니다. 실제 EEG 측정은 연결되어 있지 않으며, 실험 모드의 SSVEP 자극·판독·동적 정지는 시뮬레이션입니다. 웹에서는 클릭·키보드로 입력합니다.

언어 모델의 추천은 사용자의 의도를 확정하지 않습니다. 글자 수정, 직접 입력, 되돌리기로 원하는 말을 고르세요.
