# 이심전심 0.7: 연구 근거와 릴리스 검증

검토일: 2026-09-08. 대상은 한국어 초성 기반 언어 보조 및 웹 입력 UI다. EEG 수집기, 신호 분류기, 자극 동기화는 이번 웹 배포에 포함되지 않는다. ‘최적’이라는 임상적·통계적 결론은 내리지 않는다.

## 확인한 연구와 적용 범위

- [SpeakFaster, Nature Communications (2024)](https://www.nature.com/articles/s41467-024-53873-3): 문맥 기반 축약 확장과 KeywordAE/FillMask로 예측 실패 후 입력을 이어가는 설계. 한국어에서는 단어 첫 글자 대신 **음절 초성**, FillMask는 **한 음절** 교체를 사용한다. 영어·시선 입력의 성능 수치는 이 구현의 성능이 아니다. 직접 입력과 전체 음절 완성 후 무모델 확정을 추가했다.
- [MindChat, arXiv (2025)](https://arxiv.org/abs/2507.21435): 문맥을 이용한 단어·문장 제안과 실시간 철자 입력 결합. 프리프린트의 실험 결과를 일반화하지 않는다. 문맥 인지 생성은 웹 배포에서 활성화하고, `ENABLE_CONTEXTUAL_GENERATION=false`로 기존 생성기와 비교할 수 있다.
- [ChatBCI, arXiv 및 Scientific Reports 연결 정보](https://arxiv.org/abs/2411.15395): 후보 선택을 입력 동작으로 통합하는 방식. 후보 수는 3/5개를 선택할 수 있게 했고, 입력 단계의 잘못된 선택을 되돌리는 동작을 추가했다. 논문에 보고된 EEG 지표를 웹 클릭 지표로 대체하지 않는다.
- [Li et al., Science China Information Sciences (2026-06-11)](https://link.springer.com/article/10.1007/s11432-025-4685-0): 시선 추적·언어 모델·비동기 제어의 결합. 공개 초록까지 확인했다. 사용자 제어와 안정성이라는 설계 방향을 참고했으며 중국어 모델이나 EEG 결과를 재현했다고 주장하지 않는다.

## 구현과 수정

1. 실제 배포용 `DemoResilientLanguageModelClient`에 복구 전용 호출을 연결했다. 실패 시에도 제약을 만족하는 후보만 사용하며 fallback 여부를 응답에 표시한다.
2. 세션 API가 수동 문맥을 덮어쓰던 문제를 수정했다. 기본 웹 UI는 현재 탭을 대화의 기준으로 삼고 `/predict`에 최대 300자의 문장과 최근 5개 문맥을 보낸다.
3. `sessionStorage`에 초성·문장·문맥·개인 표현을 보관한다. 새로고침 시 초안을 복원한다. 새 탭/탭 종료 이후 보존은 보장하지 않는다. 후보는 복원하지 않아 오래된 결과를 확정하지 않는다. 이 탭의 기록 삭제 기능을 제공한다.
4. 글자 수정과 문장 확정을 별도 버튼으로 분리했다. 조회 중에는 이전 후보를 확정할 수 없으며, 취소·입력 변경·새 대화 뒤 늦게 도착한 응답은 무시한다.
5. 직접 문장 입력, 전 음절 완성 시 즉시 확정, 마지막 문장 취소, TTS 중지, 선택적 자동 조회(1.2초)를 제공한다. 자동 조회는 자동 확정이 아니다.
6. 개인 표현은 웹에서 다른 사용자와 공유하지 않는다. 외부 API 세션의 표현 조회도 세션별로 분리했다. 서버 세션은 최대 1000개, 유휴 TTL 24시간으로 제한한다.
7. NaN/무한 EEG 점수를 거절하고, 가설을 점수순으로 정렬한 뒤 상위 가설을 선택한다. 순위 점수는 보정된 확률이 아니다.
8. 유사도용 정규화는 후보별 한 번만 계산한다. 저장 문장으로 충분한 로컬 생성 요청은 모델 추론을 생략한다.
9. 운영 모드에서는 API 호출당 최대 20초, SDK 자동 재시도 0회로 지연 누적을 제한한다. 브라우저는 60초 후 조회를 중단한다. HTTP 취소가 서버에서 이미 실행 중인 LLM 과금까지 취소한다는 뜻은 아니다.
10. 배포 이미지에서 로컬 모델, 학습·평가 디렉터리, 개인 데이터, 로그, 테스트 의존성, 중복 배포 묶음을 제외한다. `/health`의 `release`로 실제 배포 버전을 확인한다.

## 검증 방법

```bash
python -m pytest -q tests
npm install --ignore-scripts
npx playwright install chromium
npm test
python -m scripts.verify_deployment --base-url https://esimjeonsim-bci-speller-hqa4.onrender.com --live
```

`--live`는 실제 모델을 사용할 수 있는 예측 요청 3회를 보낸다. 브라우저 회귀 테스트는 모델 API를 모킹해 실패·취소·복원을 재현한다. Windows에서는 `BCI_TEST_BROWSER`로 설치된 Edge 실행 파일을 지정할 수 있다.

브라우저에서 내려받는 지표는 버튼/숫자 키 동작 수, 확정·취소 횟수, API 대기시간이다. 원문 문장은 포함하지 않는다. 이는 EEG ITR, 정확도, KSR 또는 임상 의사소통 속도 측정값이 아니다.

## 후속 연구 평가

- 같은 모델·데이터·프롬프트 버전에서 문맥 생성 on/off를 비교하고 Acc@1/3/5, MRR, exact-constraint 유효율, fallback 비율과 p50/p95 지연을 보고한다.
- 한국어 독립 평가 세트와 사용자 자유 대화 과제를 분리한다. 학습 문장과 평가 문장 중복을 검사한다.
- 사용자를 대상으로 선택 횟수, 오류 복구 횟수, 완성 시간, 시각적 부담을 평가한 후 자동 조회 지연·후보 수를 조정한다.
- 실제 EEG 장치가 연결되면 자극 시각과 수집 시간 동기화, 분류기 보정, 비제어 상태 검출을 별도로 검증한다.

이번 릴리스의 자동 테스트 통과는 기능 회귀 검증이다. 사람 대상 정확도 향상이나 최고 성능을 입증하지 않는다.
