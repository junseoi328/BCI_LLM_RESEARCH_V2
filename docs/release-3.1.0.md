# 3.1.0 — 입력 집중과 40키 가독성

## 문제와 변경

대화 기록과 입력부가 한 화면을 나누면서 작은 노트북에서 자판이 아래로 밀리고,
초록색 다음 단어 후보에 연결되는 후보키는 보라색으로 표시되었다.

- 입력 집중 / 대화 함께 보기: 대화 영역만 접고 다시 연다. 초안, 학습, 대화 문맥은 변경하지 않는다. 설정은 탭에 저장한다.
- 1100px 이하 화면에서 입력부를 먼저, 대화를 뒤에 배치한다.
- 낮은 데스크톱 화면에서 문장과 말하기 버튼을 같은 행에 배치하고 간격을 줄인다. 큰 글씨 모드에는 압축 규칙을 적용하지 않는다.
- 40개 표적과 두벌식 배열을 유지한다. 키보드 제목과 단축키 안내를 추가한다.
- 다음 단어 후보와 해당 후보키의 색을 연결한다. 모든 후보키에 전체 후보를 접근성 이름과 툴팁으로 제공한다.
- 설명서에서 보장할 수 없는 0ms / 모델 완료 시간 표현을 제거한다.
- UI, 기록 내보내기 버전, 서버 health release를 3.1.0으로 맞춘다.

## 디자인 근거와 플러그인

사용자 제공 현행 화면과 [기존 Figma 초안](https://www.figma.com/design/E5Jakr2vt33EOpwSjgGPlK?node-id=2-130)을 검토했다.
초안의 ‘내가 전할 말’ 중심 위계를 현재 40키 화면에 적용했다. Figma 파일 자체는 수정하지 않았다.
Mobbin은 유료 요금제 제한으로 검색 결과를 제공하지 않았다. Higgsfield 도구는 연결 목록에 없었다.
다른 제품의 템플릿을 복제하거나 BCI 사용자 평가를 수행했다고 주장하지 않는다.

## 검증

브라우저 회귀 테스트에 집중 모드 전환 전후 상태 보존, 탭 재시작 후 설정 복원,
후보키 접근성 이름, 40개 키 수, 1366×768 집중 화면의 자판 하단 위치,
320/390/768/1440px 가로 넘침 및 키 높이 검사를 추가했다.
기존 FillMask, 세션 복구, 물리 키보드, 로컬 후보, 실험 모드 테스트도 실행한다.

1366×768 맞춤 검사는 짧은/빈 문장의 기본 글씨 모드 기준이다. 긴 문장, 여러 문장 후보,
큰 글씨, 열린 설정에서는 자연스러운 세로 스크롤을 허용한다. 모바일 10열 표적의 너비가
제한되므로 실제 EEG 입력 배치는 별도 사용자 평가가 필요하다.

## 배포 / 되돌리기

기존 main → Render 자동 배포를 사용한다. `/health` release와 `/speller`의
3.1.0 및 입력 집중 버튼을 확인한다. 회귀 발생 시 이 릴리스 커밋을 revert하거나
Render에서 이전 성공 배포로 되돌린다. 저장 데이터 형식 변경은 없다.
