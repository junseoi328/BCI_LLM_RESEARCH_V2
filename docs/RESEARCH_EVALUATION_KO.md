# 입력 전략 비교 실험실

경로: `/speller/research`. 기존 대화 화면의 입력 실험실 링크에서 접근한다.

## 연구 목적

사용자가 제공한 PDSP 제안서 3~5쪽의 초성/자모 비교, 후보 선택 반복, 문장 종료 흐름을 웹에서 먼저 평가한다. 참가자 연락처 등 PDF의 개인정보는 웹에 복제하지 않는다.

SpeakFaster(2024)의 약어 입력·수정 흐름과 ChatBCI(2026)의 문맥 기반 예측을 참고했다. 본 구현의 성능을 해당 논문의 결과와 동일시하지 않는다.

- https://www.nature.com/articles/s41467-024-53873-3
- https://www.nature.com/articles/s41598-025-25660-7

## 비교 방법

1. 같은 난이도의 목표 문장을 선정한다. 목표 문장은 서버로 전송하지 않는다.
2. 초성/자모 입력 전략과 직접 입력/개인 표현/빠른 LLM/기존 LLM 조건을 정한다.
3. 개인 기억을 고정하려면 시작 전에 기억 갱신을 끈다. 시행 중 기록 삭제는 잠긴다.
4. 조건 순서를 참가자마다 교차 배치한다. 연습 시행과 본 시행은 별도 페이지 세션으로 분리한다.
5. 문장을 완료하거나 시행 중단을 선택한다. 실패·중단도 보고한다.
6. 결과 JSON에는 원문 없이 개별 시행과 조건별 요약이 포함된다. 새로고침 전에 다운로드한다.

## 지표 정의

- 문장 시간: 시작~종료의 실제 경과시간. LLM 대기를 포함한다.
- 입력 동작: 화면 키, PC 입력 이벤트, 후보 선택, 수정. 실제 EEG 선택 수가 아니다.
- 문자 오류율: 띄어쓰기를 포함한 Unicode 문자 편집거리 / 목표 문자 수. 목표가 없으면 미측정이다.
- 첫 후보 P50: 실제로 후보가 표시된 조회의 지연시간 중앙값. 빈 응답은 제외한다.
- 서버 P95: 성공한 응답의 nearest-rank 95백분위. 실패·취소는 제외되므로 오류·중단 수와 함께 해석한다.
- 완료 시행과 중단 시행을 분리한다. 중단은 완료 시간·오류율 요약에서 제외된다.
- 비교 그룹은 조건, 입력 전략, 기억 갱신 여부다. 목표 난이도·선택한 단위·참가자 차이는 자동 통제되지 않는다.

## 개인화와 한계

단어·문장별 확정 빈도를 현재 탭에 저장한다. 모델 가중치를 훈련하는 기능은 아니다. 실제 EEG 연결, 자극 동기화, 뇌파 판별 정확도, ITR, ALS 사용자의 피로 개선은 이 실험실에서 검증되지 않는다.

LLM의 이득은 후보 응답시간 하나가 아니라 문장 완성 총시간과 수정 부담으로 판단한다. 빠른 조건은 별도 LLM 정렬·추가 다양성 생성을 생략하므로 품질 손실 가능성도 함께 평가한다.
